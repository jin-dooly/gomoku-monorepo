## 1. 용어

| 용어 | 뜻 |
|---|---|
| 방장 | 방을 만든 사람이에요. 흑을 잡고, 입장 요청을 수락하거나 거절해요 |
| 참가자 | 방 목록에서 방을 골라 입장을 요청한 사람이에요. 백을 잡아요 |
| 방 이름 | 방장의 닉네임이에요. 따로 입력받지 않아요 |
| 입장 요청 | 참가자가 방에 들어가겠다고 보내는 요청이에요. 방장이 수락해야 대국이 시작돼요 |
| 대기 중 / 대국 중 | 방의 상태예요. 대기 중 = 방장 혼자 있음, 대국 중 = 두 명이 대국하고 있음 |

## 2. 유저플로우

```
[방장]   01 홈(닉네임) → 방 만들기 → 02 대기실 → 요청 수락 → 04/05 대국 → 06 결과
[참가자] 01 홈(닉네임) → 대기 중인 방의 [입장 요청] → 03 승인 대기
                         ├ 수락됨 → 04/05 대국 → 06 결과
                         └ 거절됨 / 60초 초과 / 방장이 다른 사람 수락 → 03 거절 상태 → 01 홈
[결과]   06 결과 → 재대결(두 사람 모두 동의, 흑백 교대) → 04/05 대국
                 → 로비로 나가기 → 01 홈
[수락]   요청 수락 → VS 화면(약 2초) → 04/05 대국
[예외]   대국 중 상대 연결 끊김 → 07 (30초 대기) → 복귀하면 이어서 대국 / 시간 초과 시 남은 사람 승리
         대국 중 ⋮ 메뉴 → 08 시트(모바일) · 10 드롭다운(PC) → 09 확인창 → 기권 또는 나가기
```

초대 코드나 초대 링크는 **없어요**. 방에 들어가는 방법은 방 목록에서 고르는 것 하나뿐이에요.

## 3. 규칙

### 대국
- 15×15 판의 교차점에 돌을 둬요.
- 흑(방장)이 먼저 둬요.
- 가로·세로·대각선으로 **5개 이상** 이으면 이겨요. 6목 이상도 승리이고, 쌍삼 같은 렌주 금수는 없어요.
- 판이 가득 차면 무승부예요.

### 방과 입장
- 닉네임은 2–10자예요. **중복을 허용해요.**
- 방 목록의 각 방에는 방장 닉네임과 **생성일시(초 단위)**를 보여줘요. 형식: `2026.10.18 14:32:07 생성`. 이름이 같은 방은 이 시간으로 구분해요.
- 목록에 "대기 중 · 1/2명" 같은 인원 표시는 넣지 않아요. 당연한 정보라서 뺐어요.
- 대국 중인 방에는 "대국 중" 칩을 붙이고, 입장 요청을 보낼 수 없어요. 관전 기능도 없어요.
- 입장 요청은 **60초** 안에 방장이 응답하지 않으면 자동으로 취소돼요.
- 방장이 한 명을 수락하면 나머지 요청은 모두 자동으로 거절돼요.
- 참가자는 승인을 기다리는 동안 요청을 직접 취소할 수 있어요.

### 대국 중 / 대국 후
- 상대 연결이 끊기면 **30초** 동안 재접속을 기다려요. 그 안에 돌아오지 않으면 남아 있는 사람이 이겨요.
- **같은 사람 알아보기**: 서버가 처음 접속할 때 세션 ID를 발급하고, 브라우저 `sessionStorage`에 저장했다가 재접속할 때 보내요. 탭마다 따로라서 새로고침은 같은 사람으로 이어지고, 다른 탭은 다른 사람이에요. 짧은 끊김은 Socket.IO 연결 상태 복구로도 이어 붙여요.
- **기권**: 이번 판만 패배로 끝나고, 방에 남아서 재대결할 수 있어요.
- **방 나가기**: 대국 중이면 기권으로 처리하고 홈으로 가요. 방장이 나가면 방이 사라져요.
- **재대결**: 두 사람이 모두 동의해야 시작해요. 시작할 때 흑과 백이 바뀌어요.
- 아무나 판을 초기화하는 "게임 리셋" 기능은 **없애요**.
- 무르기는 넣지 않아요.

## 4. 화면 명세

모든 화면은 모바일(390×844)을 기준으로 그렸어요. PC 레이아웃은 [5. 공통 UI 규칙](#5-공통-ui-규칙)을 따라요.

### 01 홈 · 방 목록
- 헤더: 서비스 이름 "오목"과 서버 연결 상태(점 + "연결됨"/"연결 중").
- **서버를 깨우는 중 배너**: 서버에 연결되기 전에만 보여줘요. 문구는 "처음 접속하면 최대 1분 걸릴 수 있어요"예요(Render 무료 플랜 콜드 스타트 대응). 배너가 보이는 동안 닉네임은 입력할 수 있지만, 버튼은 비활성화돼요.
- 닉네임 입력 → 아래 안내 문구 "2–10자 · 방을 만들면 닉네임이 방 이름이 돼요".
- [방 만들기] 주 버튼.
- 방 목록: 제목 "방 목록 N"과 새로고침 버튼. 목록은 실시간으로 갱신하지 않고, 홈에 들어올 때와 새로고침 버튼을 누를 때만 불러와요. 각 행에는 방장 닉네임, 생성일시, 상태별 동작을 보여줘요.
  - 대기 중 → [입장 요청] 버튼
  - 대국 중 → "대국 중" 칩. 행을 흐리게 표시하고 누를 수 없어요.

### 02 방장 · 대기실
- 헤더: 뒤로가기(방 닫기), 방 이름(내 닉네임), "내 방" 표시.
- 안내 문구: "방 목록에 ‘지니’ 방으로 보여요. 입장 요청을 수락하면 바로 대국이 시작돼요."
- **입장 요청 목록**: 요청마다 카드를 하나씩 보여줘요. 카드에는 닉네임, "N초 후 자동 취소", [거절] / [수락하고 시작] 버튼이 있어요.
- 요청이 없을 때는 "아직 입장 요청이 없어요"를 보여줘요.
- 안내 문구: 60초 자동 취소, 한 명을 수락하면 나머지는 자동 거절.
- 참가자 슬롯 1/2: 나(흑, "방장" 표시)와 빈 슬롯(백).

### 03 참가자 · 승인 대기
- **대기 상태**:
  - "지니 님의 수락을 기다리고 있어요"
  - 내 색 안내("나는 백으로, 방장이 먼저 둬요")
  - 요청한 방의 이름과 생성일시. 같은 이름의 방과 구분하려고 보여줘요.
  - 60초 진행 막대와 `0:48` 카운트다운
  - [요청 취소] 버튼
- **거절 상태**: "입장하지 못했어요"와 이유를 도장과 문장으로 보여줘요. 버튼은 [방 목록으로], [내 방 만들기]예요.
  - 거절: 도장 "거절", "방장이 요청을 거절했어요."
  - 60초 응답 없음: 도장 "시간 초과", "60초 동안 방장의 응답이 없었어요."
  - 다른 상대와 시작: 도장 "다른 상대와 시작", "방장이 다른 상대와 대국을 시작했어요."
  - 방장이 방을 닫음(연결이 끊긴 경우 포함): 도장 "방 닫힘", "방장이 방을 닫았어요."

### VS 화면 (수락 직후)
- 방장이 수락하면 두 사람 모두 이 화면을 약 2초 보고 대국 화면으로 넘어가요.
- 위는 백(2P, 밝은 패널), 가운데 "VS", 아래는 흑(1P, 어두운 패널, "먼저 둬요"). 각 진영에 닉네임과 큰 돌을 보여줘요.

### 04 대국 · 내 차례
- 헤더: "{방장}의 방", 수 수("13수"), ⋮ 메뉴 버튼.
- **플레이어 카드 2개**(나 / 상대): 돌 색, 닉네임, 상태를 보여줘요. **지금 둘 차례인 사람의 카드에 청록 램프 테두리를 켜서 강조**하고, "내 차례"나 "두는 중"이라고 써요. 흑 카드는 어두운 패널, 백 카드는 밝은 패널이라 카드 색만 봐도 돌 색을 알 수 있어요.
- 오목판: 마지막 수에 주황 점을 찍어요. 모바일에서는 위가 상대 카드, 가운데가 판, 아래가 내 카드예요.
- **착수 미리보기(모바일·PC 공통)**: 교차점을 탭(PC는 클릭)하면 반투명한 미리보기 돌이 놓이고, 하단 [G7에 두기]를 눌러야 확정돼요. 다른 곳을 탭하면 미리보기 위치가 바뀌고, [취소]로 지울 수 있어요.
- 판 아래 범례: 상대의 마지막 수, 내가 고른 위치.

### 05 대국 · 상대 차례
- 상대 카드를 강조해요. 판은 누를 수 없어요(내 차례가 아니면 에러가 생길 일 자체가 없게 해요).
- 하단에 "도윤 님이 두고 있어요"를 보여줘요.
- 마지막 수 안내: "마지막 수 · 지니 G7".

### 06 결과 · 재대결
- 판에서 **이긴 돌(5개 이상)에 청록 링을 둘러 강조**해요.
- 아래에서 올라오는 결과 시트:
  - 결과("승리했어요")와 요약("흑 가로 5목 완성 · 총 13수")
  - 상대의 재대결 상태(예: "도윤 님이 재대결을 원해요")
  - [재대결 요청]/[재대결 수락] 버튼과 [로비로 나가기] 버튼
  - 안내 문구: "재대결하면 흑과 백이 바뀌어요"
- 플레이어 카드에는 승리/패배/무승부를 도장으로 표시해요. 상대가 기권하거나 나가거나 연결이 끊겨서 진 경우에도 도장은 **"패배"로 통일**하고, 이유는 카드의 상태 글자(기권 / 방을 나감 / 연결 끊김)와 요약 문구로 알려줘요.
- 결과별 화면 (목업: 06 결과 · 패배 / 무승부 / 기권승):
  - **승리**: 제목 "승리했어요"(청록).
  - **패배**: 제목 "졌어요"(종이색). 요약은 승리와 같은 형식이에요.
  - **무승부**: 제목 "비겼어요"(종이색), 요약 "판이 가득 찼어요 · 총 225수", 양쪽 카드에 "무승부" 도장.
  - **기권승**: 승리 링 없음. 요약 "도윤 님이 기권했어요 · 총 12수". 상대가 방에 남아 있어서 재대결할 수 있어요.
  - **상대가 방을 나감 / 연결이 끊김(30초 초과)**: 재대결할 수 없어요. 연결이 끊겨 끝난 뒤에 상대가 다시 들어와도 그 판의 재대결은 열리지 않아요. 문구는 "도윤 님이 방을 나갔어요" / "도윤 님의 연결이 끊겼어요". 내가 방장이면 [대기실로 돌아가기](방을 유지하고 02로 가서 새 상대를 기다려요)와 [로비로 나가기](방을 닫아요)를 둘 다 보여줘요. 내가 참가자일 때 방장이 나가면 방이 사라지므로 [로비로 나가기]만 있어요.

### 07 예외 · 상대 연결 끊김
- 상대 카드를 점선 테두리로 바꾸고 "연결 끊김"이라고 표시해요.
- 대화상자: "{상대} 님의 연결이 끊겼어요", 30초 진행 막대와 남은 시간, [나가기] / [계속 기다리기] 버튼.

### 08 모바일 · 대국 메뉴 시트 (⋮)
- 판 위를 어둡게 덮고, 아래에서 시트가 올라와요.
- 항목(위에서부터):
  1. **기권하기**: "이번 판만 패배로 끝내요 · 재대결할 수 있어요"
  2. **방 나가기**: "기권으로 처리되고 방 목록으로 돌아가요"
  3. (구분선) **규칙 보기**
  4. [닫기]
- 메뉴가 열려 있는 동안 ⋮ 버튼을 눌린 상태(회색 배경)로 표시해요.

### 09 모바일 · 기권/나가기 확인창
- 기권: 제목 "기권할까요?", 설명 "이번 판은 {상대} 님의 승리로 끝나요. 결과 화면에서 재대결을 요청할 수 있어요.", 버튼 [계속 두기] / [기권하기].
- 나가기: 제목 "방에서 나갈까요?", 설명 "대국 중에 나가면 기권으로 처리돼요.", 버튼 [계속 두기] / [기권하고 나가기].
- 되돌릴 수 없는 버튼만 빨강(`#F0555A`)으로 칠해요. 취소 쪽 버튼이 왼쪽이에요.

### 10 PC · 대국 메뉴 드롭다운
- ⋮ 버튼 바로 아래에 오른쪽 정렬로 열려요. 항목과 설명 문구는 08과 같아요.
- PC 대국 레이아웃: 헤더(오목 · 방 이름 · 수 수 · ⋮), 왼쪽에 크게 키운 판, 오른쪽에 플레이어 카드를 세로로 쌓은 사이드 패널. 화면이 좁아지면 사이드 패널이 판 아래로 내려가요.

### 컴포넌트 · 오목판
- 돌은 **교차점**에 둬요. 화점(별 표시) 5개를 그려요.
- 표시 요소: 마지막 수 점(주황 `#FF6B3D`), 착수 미리보기(반투명 돌 + 청록 점선), 승리한 돌 링(청록 `#3FD6C6`).
- 돌은 10×10 도트 스프라이트(SVG, `shape-rendering: crispEdges`)로 그려요. 판은 도트 나무색이고, 선은 2px이에요.
- 돌 모양을 이모지로 그리지 않아요. 기기마다 다르게 보여서요.

## 5. 공통 UI 규칙

- **반응형**: 모바일과 PC를 똑같이 중요하게 다뤄요. 모바일에서는 판이 화면 너비에 맞아야 해요(390px 화면 기준 342px). PC에서는 판을 키우고 사이드 패널을 붙여요.
- **⋮ 메뉴**: 대국 중(04, 05, 07)에만 보여줘요. **모바일은 아래에서 올라오는 시트, PC는 드롭다운**이에요. 대기실, 승인 대기, 결과 화면에는 넣지 않아요.
  - 시트로 정한 이유: 엄지가 닿는 위치, 되돌릴 수 없는 항목에 큰 터치 영역, 설명 한 줄을 넣을 공간, 06 결과 시트와 같은 패턴.
  - 시트가 판 일부를 가리는 문제는 일단 그대로 둬요.
- **되돌릴 수 없는 동작**(기권, 나가기)은 항상 확인창을 거쳐요.
- **차례와 색**은 플레이어 카드 강조 하나로 알 수 있어야 해요. 사용자가 두 정보를 따로 보고 맞춰볼 일이 없게 해요.
- **실시간 상태는 숨기지 않아요**: 연결 상태, 요청 남은 시간, 상대가 두는 중, 연결 끊김을 항상 화면에 보여줘요.
- **문구**: 한국어만 써요. 서버 에러 문구를 영어 그대로 노출하지 않아요. 에러는 화면 맨 위 배너 대신 관련된 위치 가까이에 보여줘요.
- **터치 영역**은 최소 44px이에요.
- **숫자**(시간, 카운트다운)는 고정폭 숫자(`tabular-nums`)로 표시해요.

## 7. 소켓 이벤트

2026-10-18에 확정했어요. 정의는 [`packages/shared/src/protocol`](../packages/shared/src/protocol)(`events.ts`의 타입, `schemas.ts`의 Zod 스키마)에 있고, **코드가 기준이에요**. 이 표는 한눈에 보기 위한 요약이에요.

- 요청/응답이 필요한 C→S 이벤트는 Socket.IO acknowledgement로 `{ ok: true, data } | { ok: false, error }`를 돌려받아요. 서버는 에러 코드만 보내고, 한국어 문구는 클라이언트가 정해요.
- 남은 시간은 기기 시계 차이를 피하려고 절대 시각 대신 `remainingMs`로 보내요.
- 돌 색은 `'black' | 'white'`, 좌표는 `{ row, col }`(0–14, 위·왼쪽이 0)이에요. 화면 표기는 열 A–O, 행은 아래쪽부터 1–15예요(예: `G7`).

| 방향 | 이벤트 | 용도 |
|---|---|---|
| C→S | `room:list` | 방 목록 조회. 홈 진입과 새로고침 버튼에서만 불러요 |
| C→S | `room:create` | 방 만들기 |
| C→S | `room:close` | 방장이 대기실에서 방 닫기 |
| C→S | `room:leave` | 방 나가기. 두는 중이면 상대 승리. 참가자가 나가면 방장은 방에 남고, 방장이 나가면 방이 사라져요 |
| C→S | `room:reopen` | 상대가 나간 뒤 방장이 방을 유지하고 대기실로 돌아가기. 방이 다시 '대기 중'이 돼요 |
| C→S | `join:request` / `join:cancel` | 입장 요청과 요청 취소 |
| C→S | `join:accept` / `join:reject` | 방장의 수락과 거절 |
| S→C | `join:requests` | 방장에게 대기 중인 요청 전체 목록(도착·취소·만료될 때마다) |
| S→C | `join:resolved` | 참가자에게 결과: 수락 / 거절 / 60초 초과 / 다른 상대와 시작 / 방 닫힘 |
| C→S | `game:move` | 착수 |
| S→C | `game:state` | 판, 차례, 내 색, 두 사람 닉네임, 마지막 수, 수 수 |
| C→S | `game:resign` | 기권 |
| S→C | `game:over` | 승자, 이유(5목 / 무승부 / 기권 / 나감 / 연결 끊김), 이긴 줄의 방향과 돌 좌표, 수 수 |
| C→S | `rematch:request` / S→C `rematch:status` | 재대결 요청과 상태. 둘 다 요청하면 색을 바꿔 새 판의 `game:state`가 와요 |
| S→C | `opponent:left` | 결과 화면에서 상대가 나가거나 연결이 끊겼어요. 재대결할 수 없어요(두는 중이면 대신 `game:over`) |
| S→C | `opponent:disconnected` / `opponent:reconnected` | 상대 연결이 끊겨 30초 기다리는 중 / 돌아옴 |
| S→C | `session:assigned` | 연결할 때마다 세션 ID. 클라이언트는 sessionStorage에 저장했다가 handshake `auth.sessionId`로 다시 보내요 |
| S→C | `session:resume` | 방에 있던 사람이 다시 연결하면(새로고침 포함) 지금 있던 곳의 스냅샷 |
